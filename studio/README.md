# Studio

Remotion project for the channel. Shared folder copy is the working copy (no node_modules).
- Setup: `npm install`, then render with
  `npx remotion render src/index.ts <Comp> out/x.mp4 --browser-executable=/opt/pw-browsers/chromium_headless_shell-*/chrome-linux/headless_shell --scale=0.5`
- Shared components: `src/components/`. Index: `library/INDEX.md`.
- Fonts are bundled in `public/fonts` (Inter is a placeholder until BRAND.md picks fonts).
- See `/mnt/project-files/starter/TECH_GOTCHAS.md`.
